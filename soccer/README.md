# Soccer starter

- **Dataset:** [StatsBomb Open Data](https://github.com/statsbomb/open-data) - free event data (competitions, matches, and every on-ball event). Credit StatsBomb.
- **Also see:** [Impect Open Data](https://github.com/ImpectAPI/open-data) - a full Bundesliga season, used in our flagship [xg-for-beginners](https://github.com/nhssaa/xg-for-beginners) lesson (its license allows use at the source, not redistribution, so notebooks load it live).
- **Starter notebook:** `starter_notebook.py` - load the 2018 World Cup final, count shots and goals by player.
- **Run it:** https://molab.marimo.io/github/nhssaa/sports-data-starters/blob/main/soccer/starter_notebook.py (add `/wasm` for the interactive no-sign-in version)

# Football (NFL) starter

- **Dataset:** [nflverse](https://github.com/nflverse/nflverse-data) - schedules, scores, play-by-play, rosters and more, updated by the community. Credit nflverse.
- **Starter notebook:** `starter_notebook.py` - builds Elo power ratings from every regular-season final score since 2015.
- **Run it:** https://molab.marimo.io/github/nhssaa/sports-data-starters/blob/main/football/starter_notebook.py (add `/wasm` for the interactive no-sign-in version)

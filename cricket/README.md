# Cricket starter

- **Dataset:** [Cricsheet](https://cricsheet.org/) - free ball-by-ball JSON for T20, ODI, and Test cricket (IPL, WPL, internationals, and more). Credit Cricsheet.
- **Starter notebook:** `starter_notebook.py` - downloads every Women's Premier League T20 (~370 KB) and answers "bat first or chase?" from match outcomes.
- **Run it:** https://molab.marimo.io/github/nhssaa/sports-data-starters/blob/main/cricket/starter_notebook.py (add `/wasm` for the interactive no-sign-in version)

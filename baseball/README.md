# Baseball starter

- **Dataset:** the [Lahman Baseball Database](https://www.seanlahman.com/baseball-archive/statistics/) (Sean Lahman), mirrored as CSVs by [Rdatasets](https://github.com/vincentarelbundock/Rdatasets). Credit both.
- **Starter notebook:** `starter_notebook.py` - Bill James's Pythagorean expectation tested on 20+ seasons of team results.
- **Run it:** https://molab.marimo.io/github/nhssaa/sports-data-starters/blob/main/baseball/starter_notebook.py (add `/wasm` for the interactive no-sign-in version)

# Hockey starter

- **Dataset:** the NHL's public web API (`https://api-web.nhle.com/v1/...`) - live standings, scores, rosters. No key. Credit the NHL. For richer free data see [MoneyPuck](http://moneypuck.com/data.htm).
- **Starter notebook:** `starter_notebook.py` - pulls today's standings and fits how much goal differential explains points.
- **Run it:** https://molab.marimo.io/github/nhssaa/sports-data-starters/blob/main/hockey/starter_notebook.py (add `/wasm` for the interactive no-sign-in version)
